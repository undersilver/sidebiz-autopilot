# SideBiz Autopilot v2

毎日1件の一般読者向け記事を生成・校閲し、あなたが承認したものだけ公開する副業自動化システムです。

## v2で追加した機能

- 初稿とは別のAIによる編集校閲
- 10点満点誤回答の自動補正
- 校閲80点未満・未解決出典あり・重大問題ありの公開停止
- ピコロン入り1280×670サムネイルの自動作成
- 記事一覧へのサムネイル表示
- Issueコメントからの自動修正
- 修正版の再校閲
- 週次運用レポート
- 月次のKindle・有料記事用原稿
- 承認済みリンクだけを使うアフィリエイト設定ファイル

## 安定化修正版で強化した点

- pass・80点以上・highリスクなし・未解決出典なしを全工程で統一判定
- 「要出典」「今後調査が必要」が本文に残る場合の強制公開停止
- リポジトリ所有者以外による `/revise` 実行の禁止
- 修正版だけを再校閲し、Issue本文とラベルを更新
- 公開処理で作成した同一成果物をGitHub Pagesへ渡す方式に修正
- 書き込みWorkflowを直列化し、自動コミットの競合を抑制
- 初期トップページの画像参照を `pikoron.png` に統一

## 更新方法

既存リポジトリへ、このZIPの中身を同じ階層で上書きします。

特に次を更新してください。

- `.github/workflows/`
- `scripts/`
- `config/`
- `docs/assets/style.css`
- `docs/assets/pikoron.png`
- `requirements.txt`

## 毎日の操作

### 問題がない場合

1. Issuesで当日の候補を確認
2. `approve`ラベルを追加
3. 1時間以内、または手動で`Publish approved content`を実行
4. サイトへ公開

### 修正が必要な場合

Issueのコメント欄へ、先頭に `/revise` を付けます。

```text
/revise 初心者向けの具体例を2つ追加し、専門用語を減らしてください。
```

コメントすると、AIが下書きとサムネイルを修正します。

その後、

`Actions → Revalidate revised drafts → Run workflow`

を実行します。再校閲結果がIssueへコメントされます。合格したら`approve`を付けます。

## サムネイル

記事タイトル、カテゴリー、ピコロンを使い、1280×670pxで自動生成します。
画像生成AIを使わないため、無料で安定して動作します。

## 週次レポート

毎週日曜19時に、生成件数、公開件数、平均校閲スコア、カテゴリー内訳をIssueへ作成します。
現時点ではアクセス数や売上ではなく、システム内の運用実績です。

## 月次商品原稿

毎月1日8時に、前月公開記事をまとめてMarkdown原稿にします。

```text
products/monthly/YYYY-MM-manuscript.md
```

販売前に重複、章順、出典、権利を確認してください。

## アフィリエイト

`config/affiliate_links.json` に、契約済みの正規リンクだけを登録します。初期状態では無効です。
AIが勝手に未契約リンクを掲載することはありません。
